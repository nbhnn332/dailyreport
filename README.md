# SYBERCEC — DAILY REPORT

Personal daily study & work reporting web application backed by Google Sheets via Google Apps Script.

## Features
- Fast daily reporting (under 20 seconds)
- Minimal dark modern UI optimized for mobile and desktop
- Automatic date formatting (`DD/MM/YYYY`)
- Direct integration with Google Sheets (never overwrites previous entries)
- Recent reports view (latest entries)

## Tech Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Backend / Storage: Google Sheets + Google Apps Script Web App

## Local Development
```bash
npm run dev
```
Runs at `http://localhost:3000`.
